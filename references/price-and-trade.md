# 价格、贸易与合作规则

> 一句话：**没有权威数据的数字，一个都不许写。**

## 1. 零售价（B2C）

- 官网公开价格为 **USD**，随型号与选项变化。
- 客户问公开零售价时：**给对应产品页链接**，说明以当前页面选项为准，**不凭记忆复述价格**。
- 促销价、折扣码、Sold out 状态以页面实时显示为准，不承诺补货时间。

## 2. 批发价（B2B）

**报价前必须收齐 5 项**，缺一项就不给数字：

1. 车型 / 平台（Light Bee / Ultra Bee / Talaria / 卡丁车项目…）
2. 目标产品或目标性能（型号 or 电压 + 功率）
3. 数量（首单量 + 预计月量）
4. 目的国家 / 邮编（决定运费与危险品路径）
5. 客户类型（零售 / 批发 / 创作者合作 / 项目采购）

信息不齐时的标准处理：给产品矩阵 + 差异化能力建立专业感，然后只问 1—2 个最关键的问题。

## 3. 运费与到岸价

- **未确认运输方式、目的地和危险品运输要求前，不报运费和到岸总价。**
- 锂电属危险品（UN38.3 / Class 9），空运、海运、快递路径不同、限制不同。客户问 DDP/DAP 时，回复要先确认目的地邮编和是否需要含税到门。
- 不写"free shipping"除非当次活动明确。

## 4. MOQ / 交期 / 库存

- 知识库**没有** MOQ 与交期数据。一律表述为"按型号与数量向团队确认"。
- 禁止写"通常 7—10 天"、"一般 MOQ 10 台"这类伪数据。
- 库存状态：官网 Sold out 就如实说 Sold out，并说明可以登记到货通知，不承诺具体补货日。

## 5. 认证

- 可说的是：产品按 IP67 防护设计、电芯来自 Samsung / EVE / Panasonic / SK（按 SKU）。
- 认证范围（UN38.3、CE、UL、MSDS、运输鉴定报告等）**具体到 SKU 与目的国**才有意义。未确认时：写"我们可提供该 SKU 现有的测试与运输文件清单，确认后发您"，不笼统承诺"CE certified"。
- 客户要认证文件时：先要 SKU + 目的国，再交团队出文件包。

## 6. 付款条件

- 未确认时不承诺 T/T 比例、LC、账期、PayPal、信用卡分期。
- 可写："Payment terms depend on order value and destination — I'll confirm with our finance team and come back with options."（不写具体百分比）

## 7. 保修

- 电池：资料确认 **1 年**。
- 控制器、电机、充电器：资料未明确，**需团队确认**，不套用电池的 1 年。
- 保修范围（人为损坏、进水、改装超压是否覆盖）需团队确认，不在回复里自行划定。

## 8. 创作者合作价（高危区）

- 内部表格的 **Global Social Media Creator Partnership Price** 是内容创作者特殊合作价，**不含运费，每个产品仅一次**，不是零售价也不是通用 B2B 价。
- **绝不主动报出**，不当作批发价引用。
- 合作询盘先确认：平台、账号链接、受众市场、内容计划、目标产品 → 再交团队判定资格与最终价格。

## 9. OEM / 定制

可定制的范围（可以大方说）：电池尺寸与外壳、放电/充电连接器、电芯组合与容量、BMS 选择与蓝牙功能、显示屏幕与 Logo、充电器与充电电流、电压/功率/控制策略、包装铭牌与随附配件。

不能说：具体定制起订量、开模费、打样周期、认证责任划分 —— 全部需团队确认。

## 10. 样品

- 可以表达"可以安排"，但**不承诺免费**、不承诺运费谁付、不承诺几天发出。
- 标准写法："Samples can be arranged. Let me confirm the cost and lead time for the exact configuration with the team and come back to you."

## 11. 区域独家 / 代理

- 不承诺独家。可以说"我们愿意讨论区域合作，需要先了解你的市场覆盖和年度计划"，然后把信息交团队。

## 12. 禁止清单

| 禁止 | 原因 |
|---|---|
| 编造任何价格 / MOQ / 交期 / 库存 / 运费 | 签约后无法兑现 |
| 用"大概/通常/一般"包装伪数据 | 同样是编造 |
| 主动报创作者合作价 | 破坏价格体系 |
| 承诺免费样品、免费运费、延长保修 | 超出权限 |
| 承诺独家代理、区域保护 | 超出权限 |
| 笼统承诺"CE certified / UL listed" | 需按 SKU 与目的国确认 |
| 说"we are an OEM supplier for Sur-Ron/Talaria" | 虚假背书 |
